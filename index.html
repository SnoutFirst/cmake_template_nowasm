cmake_template_nowasm

What it does

$ cmake_template_nowasm --name you
Hello, you!

It is deliberately tiny: the point of the template is the surroundings, not the program. --help and a --version that matches what CMake was told are covered by the tests, which also keeps the CLI parsing (CLI11) and the configured config.hpp exercised.

What is inherited from upstream

  • CMake ≥ 3.29, C++23, and the cmake_template_nowasm_* option namespace.
  • Sanitizers (ASan/UBSan on by default where supported), hardening (_FORTIFY_SOURCE, stack protector, CFI on MSVC), warnings-as-errors, clang-tidy and cppcheck, IPO/LTO.
  • CPM-fetched dependencies: fmt, spdlog, Catch2 and CLI11. A parent project can supply its own versions; every fetch is guarded by if(NOT TARGET ...).
  • Catch2 unit tests and constexpr tests, a libFuzzer harness that switches on when a fuzzing sanitizer is available, coverage collection with gcovr / OpenCppCoverage, and CPack packages whose names embed the compiler and the commit sha.
  • The GitHub Actions matrix (Linux/macOS/Windows × GCC/Clang/MSVC × Debug/Release, Ninja Multi-Config plus one plain Makefiles and four Visual Studio builds), CodeQL, the clang-format bot, Dependabot and the dev container.

What was changed

  • WebAssembly removed. cmake/Emscripten.cmake, the web/ assets, the EMSCRIPTEN branches in the options and the "Build Intro WASM and Deploy to GitHub Pages" workflow are gone. Nothing conditional is left behind: the native build is the only build.
  • The example application replaced. The FTXUI game (intro) became a hello-world CLI named after the project. FTXUI and lefticus/tools, which only the game used, are no longer fetched.
  • Downloads published. CI packages one Release binary per platform, uploads it as a workflow artifact, attaches the archives to a rolling ci-latest release and publishes a download page to GitHub Pages — the same mechanism used by QtWatchAllVideos.
  • Two fixes the upstream generation step left behind. CMakePresets.json still named its analyzer options myproject_*, so the Windows presets disabled nothing and presets.windows_disables_static_analysis failed; and the factorial declaration did not name its parameter, which modern cppcheck rejects (this failed every macOS job).
Built from main at commit 665950e by GitHub Actions. The archives are attached to the rolling CI release so that no build output is ever committed. Older builds are kept as workflow artifacts, and tagged versions also get a GitHub Release each.
