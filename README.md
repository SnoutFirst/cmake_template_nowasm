## About cmake_template_nowasm
WASM-free variant of cpp-best-practices/cmake_template

## WebAssembly Demo

Try the live WebAssembly demo:
- Main: [https://SnoutFirst.github.io/cmake_template_nowasm/](https://SnoutFirst.github.io/cmake_template_nowasm/)
- Develop: [https://SnoutFirst.github.io/cmake_template_nowasm/develop/](https://SnoutFirst.github.io/cmake_template_nowasm/develop/)

The `main` branch deploys to the root, `develop` to `/develop/`, and tags to `/tagname/`.
